## Identifying and Defining

### Mind map

### Hypothesis 
The more time a student spends gaming a day, affects their (math or english) grades negatively.

### Functional requirements
The system should be able to load certain file types and handle errors in file loading, it'd need to handle missing values and allow for filtering/sorting/grouping data. The system would need to allow for median and mode. The data will be visualised with a bar graph, using Matplotlib. The x-axis being how many hours gaming, the y-axis being their overall grade
### Non-functional requirements



Data Reporting: What output should the system include, and do we need to store the final dataset somewhere (e.g. .csv or .txt file)?
