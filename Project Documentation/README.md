# **Gaming Habits and Academic Performance Analysis System**

## Description

This project analyses survey data about gaming habits and academic performance, for GHS students. Users can view datasets, search up keywords for information, and generate graphs to identify patterns between gaming time and English improvement.

## Features

The main functions of the program is:

- View dataset
- View visualisation
- Search/filter data
- Data summary
- Research Conclusion
- Exit

## Requirements

You need:

1. Github Account
2. Github Desktop
3. Visual Studio Code
4. Download pandas and matplotlib

## Installation

1. Download the project files from github.com
2. Clone them into github desktop
3. Then open with visula studio code
4. Download pandas and matplotlib
5. Now run the main.py file

## How to use

1. Run the main.py file
2. Choose the options presented in the main menu
3. Return to the main menu. when finished
4. Repeat with new options until all options and sub-options are complete, or until you get bored
5. Exit program from main menu

## Dataset information

The dataset contains survey responses about GHS students’ gaming habits and correlation with their English performance.

## Limitations

- The survey was self-reported (biased)
- Dataset is small
